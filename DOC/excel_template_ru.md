# Шаблон Excel для кнопок «...»

Все три кнопки «...» читают файл одинаково: это делает функция [`read_excel_constraints`](file:///E:/Синхронизация/Git/TSV-Converter/converter.py#L242-L290). Кнопки стоят рядом с полями «Разделить на файлы по столбцу», «Разделить на листы по столбцу» и «Фильтр по столбцу». Различается только то, как программа потом использует загруженные пары.

## 1. Как выглядит файл

| | **A** | **B** |
|---|---|---|
| **1** | ID проекта | 02849b3c-f930-4b10-b132-248adeb7c1cb |
| **2** | Код ТТ       | 011581 |
| **3** | Код ТТ | 011761 |
| **4** | Название ДМП | Стойка Бразилия |

- **Столбец A** — название столбца из вашего TSV/CSV. Оно должно совпадать с заголовком **символ в символ**, включая регистр.
- **Столбец B** — одно значение этого столбца.
- **Одна строка Excel — одна пара «столбец = значение».** Чтобы задать несколько значений для одного столбца, повторите название столбца в нескольких строках.
- Программа читает только **первый лист** книги, только столбцы **A и B**. Остальные листы и столбцы игнорируются.

По итогу указанного примера из файла TSV будут выбраны строки соответствующие проекту "02849b3c-f930-4b10-b132-248adeb7c1cb" для ТТ "011581" и "011761" оборудования "Стойка Бразилия"

## 2. Технические правила

| Правило | Что будет при нарушении |
|---|---|
| Формат файла только **`.xlsx`** (старый `.xls` не поддерживается) | Ошибка чтения |
| Строка заголовка необязательна. Первая строка пропускается, если в A написано `Столбец`, `Column`, `1 столбец`, `Название столбца` или `Имя столбца`, **или** в B написано `Значение`, `Value` или `2 столбец` (регистр не важен) | Если заголовок назван иначе, он будет прочитан как обычная пара |
| Полностью пустые строки | Пропускаются |
| Заполнено A, но пусто B | Строка молча пропускается |
| Заполнено B, но пусто A | **Ошибка**: «пустое название столбца (A)» |
| Формулы и ошибки Excel (`=...`, `#N/A`) | **Ошибка**: нужны только значения. Скопируйте ячейки и вставьте их как значения |
| Ни одной корректной пары | **Ошибка**: «В файле нет ограничений» |
| Столбца из A нет в загруженном TSV | Предупреждение, эти строки пропускаются |
| Пробелы по краям в A и B | Обрезаются автоматически |

> [!IMPORTANT]
> Значения сравниваются с данными **точно, как текст**. Если в TSV написано `Москва ` (с пробелом) или `москва`, пара `Москва` с ним не совпадёт.

> [!WARNING]
> **Числа, коды и даты храните в Excel как текст** (формат ячейки «Текстовый» или апостроф перед значением: `'00123`). Иначе Excel исказит значение: `00123` превратится в `123`, а дата станет `2024-01-15 00:00:00`. Такое значение не совпадёт с данными.

## 3. Как программа использует пары

### «Фильтр по столбцу» → оставить только нужные строки
- Несколько значений **одного** столбца объединяются через **ИЛИ**.
- Условия по **разным** столбцам объединяются через **И**.
- Пример из таблицы выше: в результат попадут строки, где `(Регион = Москва ИЛИ Казань) И Статус = Активен`.
- Это условие работает **вместе** с обычным фильтром из выпадающего списка: строка должна пройти оба.

### «Разделить на файлы» / «Разделить на листы» → раскладка данных
- **Каждая пара — свой файл (или лист).** Пример выше даст три файла или листа: `Москва`, `Казань`, `Активен`, плюс **«Все остальное»** для строк, которые не подошли ни под одну пару.
- Ничего не отфильтровывается: каждая строка куда-нибудь попадёт.
- Если строка подходит под **несколько** пар (например, Москва и Активен), она будет записана **в каждый** соответствующий файл или лист.
- **Имена:** файл называется `<исходное имя> (conver_ЧЧ.ММ.СС)_<значение>.xlsx`, лист — `<значение>`. Если одно и то же значение встречается в разных столбцах, к имени добавится название столбца: `Регион_Москва`. Запрещённые символы заменяются на `_`, имя листа обрезается до 29 символов.
- Если загрузить шаблон для листов, выпадающий список «на файлы» сбрасывается, и наоборот. Если всё же включены оба измерения, результатом будет «файлы × листы» (программа предупредит об этом в логе).

## 4. Прочие условия

- Кнопки работают, только когда в списке **ровно один** исходный файл.
- Пока шаблон активен, кнопка выглядит как `...•`. Чтобы заменить или сбросить шаблон, нажмите её снова и выберите **«Заменить» / «Очистить» / «Отмена»**.

## 5. Готовые примеры

**Разделение на файлы** — отдельный файл на каждого менеджера плюс «Все остальное»:

|---|---|

| Менеджер | Петров |
